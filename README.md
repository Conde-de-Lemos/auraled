# Auraled para Windows

Auraled controla tu kit de iluminación desde una sola aplicación, con su motor incluido. No requiere instalar Prismatik por separado.

## Descargar

[Descargar Auraled 5.2.2-beta.3 para Windows de 64 bits](https://github.com/Conde-de-Lemos/auraled/releases/download/v5.2.2-beta.3/Auraled-5.2.2-beta.3.zip)

1. Descarga el ZIP y extrae todo su contenido.
2. Abre `Auraled_V5_2_2.exe` dentro de la carpeta extraída.
3. Sigue la guía de Auraled para configurar tu monitor y verificar los colores.

Mantén juntos los archivos del paquete. Incluye componentes, fuentes correspondientes, licencias e informes de revisión. El ZIP de la aplicación es el archivo **Auraled-5.2.2-beta.3.zip**; los archivos automáticos «Source code» de GitHub contienen únicamente este repositorio de distribución.

Requisitos del paquete: Windows 10 o posterior de 64 bits, .NET Framework 4.7.2 o posterior, Windows PowerShell 5.1 y Microsoft Edge WebView2 Runtime.

Esta descarga conserva el estado beta.3 del paquete original. Sus informes detallan las pruebas realizadas y pendientes.
