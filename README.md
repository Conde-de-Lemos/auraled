# Auraled para Windows

Controla tu kit de iluminación desde una sola aplicación con su motor incluido. No requiere instalar Prismatik por separado.

## Instalar Auraled

[Descargar el instalador EXE de Auraled 5.2.2-beta.3](https://github.com/Conde-de-Lemos/auraled/releases/download/v5.2.2-beta.3/Auraled-5.2.2-beta.3-Setup-r1.exe)

1. Abre el instalador y sigue sus pasos.
2. Abre Auraled desde el menú Inicio.
3. Sigue la guía de Laura para configurar tu monitor y verificar los colores.

Un solo EXE de 154 MB contiene la aplicación, el motor, sus componentes, fuentes y licencias. Instala para tu usuario e incluye desinstalador; la desinstalación conserva tus ajustes. No necesitas descargar ni extraer el ZIP.

Windows 10 o posterior x64, .NET Framework 4.7.2 o posterior y Windows PowerShell 5.1. Si falta Microsoft Edge WebView2 Runtime, el instalador lo prepara desde Microsoft y necesita Internet.

Aplicación y motor 5.2.2.0 / 5.2.2-beta.3 sin cambios; empaquetador 5.2.2.1 / Instalador 1. Se conserva el estado beta y los pendientes físicos descritos en los informes. Se verificaron instalación, reinstalación, 1504 archivos idénticos, 24 peticiones con motor Virtual y desinstalación con ajustes intactos.

SHA-256 del instalador: `96574a213581517696a9324bb76c80e616d87eb24ab376e25e2cda2260d4d4b1`.
