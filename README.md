# Istalador Auraled

Auraled 5.2.2-beta.3 · Instalador 2 para Windows x64. Una sola aplicación con su motor de iluminación incluido.

[Descargar Istalador Auraled](https://github.com/Conde-de-Lemos/auraled/releases/download/v5.2.2-beta.3/Istalador.Auraled.exe)

1. Abre el instalador y sigue sus pasos.
2. Abre **Aruraled** desde el menú Inicio. El ejecutable instalado es **Aruraled.exe**.
3. Sigue la guía de Laura para configurar tu monitor y verificar los colores.

No necesitas extraer un ZIP ni instalar Prismatik aparte. El instalador incluye los componentes, fuentes correspondientes y licencias; añade accesos directos y un desinstalador que conserva los ajustes personales.

El archivo local se genera como `Istalador Auraled.exe`; GitHub normaliza su espacio como un punto en el nombre de descarga `Istalador.Auraled.exe`.

Aplicación y motor originales: 5.2.2.0 / 5.2.2-beta.3. Empaquetador: 5.2.2.2 / Instalador 2. Esta revisión cambia los nombres solicitados y sus accesos directos, conservando el código y los binarios de la aplicación. Las pruebas de instalación, reinstalación, 1504 archivos, acceso directo a Aruraled.exe, 24 peticiones con motor Virtual y desinstalación fueron correctas. Se mantienen los pendientes físicos de la beta.

Windows 10 o posterior x64, .NET Framework 4.7.2 o posterior y Windows PowerShell 5.1. Si falta WebView2 Runtime, el instalador lo prepara desde Microsoft y requiere Internet.

SHA-256: `147ec46f9ae2de88c6a6a6adcef870e2e876de9c1c3079ae102ceb77e10328b7`.

El instalador 1 y el ZIP portable original permanecen en [la publicación de GitHub](https://github.com/Conde-de-Lemos/auraled/releases/tag/v5.2.2-beta.3). El ZIP portable conserva el nombre histórico Auraled_V5_2_2.exe y debe extraerse completo. Los archivos automáticos «Source code» de GitHub contienen únicamente este repositorio de distribución.
