# Istalador Auraled

Auraled V5.2.3 · 5.2.3-beta.4 para Windows x64. Una sola aplicación con su motor de iluminación incluido.

[Descargar la última versión de Auraled](https://auraled-flow.marketing-lemos-agencia.workers.dev/descargar/auraled)

1. Cierra Auraled desde «Salir» junto al reloj antes de actualizar.
2. Ejecuta el instalador y sigue sus pasos. Puedes actualizar sobre V5.2.2 sin desinstalar primero.
3. Abre **Aruraled** desde Inicio y continúa con la guía de Laura.

El enlace de descarga es permanente: selecciona la publicación más reciente con el archivo `Istalador.Auraled.exe`, incluidas las betas. Las nuevas versiones pueden tardar hasta cinco minutos en aparecer. Los borradores de GitHub no se ofrecen.

V5.2.3 recupera la ventana al ejecutar otra vez el programa, corrige el texto `[object Promise]`, restaura el monitor interactivo con punto y flecha en Montaje y Laura, y conserva abiertos los ajustes hasta que el usuario decida cerrarlos.

Aplicación e instalador: 5.2.3.0. Motor WASAPI: 5.2.2.0, sin cambios. El instalador incluye componentes, fuentes correspondientes, licencias, accesos directos y desinstalador. No necesitas instalar Prismatik aparte.

Windows 10 o posterior x64, .NET Framework 4.7.2 o posterior y Windows PowerShell 5.1. Si falta WebView2 Runtime, el instalador lo prepara desde Microsoft y requiere Internet.

[Publicación V5.2.3 y notas](https://github.com/Conde-de-Lemos/auraled/releases/tag/v5.2.3-beta.4)

Instalador: 156.967.958 bytes. SHA-256: `95c31452104448c29dc47cdbec4ae65c29e32a1dfe37dfc7000e5fb35cc56cba`.

Se comprobaron la reapertura, el motor Virtual, los ajustes, la importación, el audio real de Windows y la interfaz. La instalación de V5.2.3 sobre una instalación real y la prueba física USB permanecen pendientes; sigue siendo una beta.

Las versiones anteriores, incluido el instalador de [V5.2.2](https://github.com/Conde-de-Lemos/auraled/releases/tag/v5.2.2-beta.3), permanecen disponibles. Los archivos automáticos «Source code» de GitHub contienen este repositorio de distribución; las fuentes de la aplicación y del motor acompañan al instalador.

Para mantenimiento: conservar el nombre del activo `Istalador.Auraled.exe` en cada nueva publicación; no es necesario editar el botón de la web. Las carpetas usan versiones con puntos, por ejemplo `Auraled V5.2.3`, sin sufijo BORRADOR. Cada cambio posterior lleva una nueva versión y conserva las entregas anteriores.
